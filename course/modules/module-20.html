Module 20: SAP Analytics Cloud (SAC)

For beginners: SAP Analytics Cloud (SAC) is SAP’s cloud BI and planning tool. You build stories (dashboards with charts, tables, and filters), connect to data from S/4HANA, Datasphere, BW, IBP, or files, and share with users. SAC also does planning (budgets, forecasts, write-back) and predictive analytics. It is SaaS only—one place to report and plan across ERP and cloud. You do not write SQL here; you pick a data source and drag-and-drop dimensions and measures. Key terms: story, model, live vs import connection, planning.

SAP SAC provides BI, planning, and predictive analytics in the cloud. It connects to S/4HANA, BW, Datasphere, IBP, and files.

Purpose and scope

SAC provides: Stories: The main canvas—add widgets (charts, tables, maps, filters), connect to a data source (model, dataset, live connection), and build dashboards. Digital boardroom: Presentation-style views for meetings; linked to live data. Planning: Create planning models (versions, dimensions); data entry and allocation; write-back. Predictive: Automated insights, forecasting, and classification using built-in ML. Data connection: Live connection (real-time query) or import (data replicated into SAC). Connections to S/4HANA (via OData or BW), Datasphere (recommended semantic layer), BW, IBP, and file upload.

Features in detail

  • Stories: Create a story; add data source (connection + model or dataset). Add charts (bar, line, pie, etc.), tables, maps, filters. Drill-down and cross-filter. Share with users and teams.
  • Models and datasets: Model = semantic layer (dimensions and measures) for import data. Dataset = flattened data for stories. Live connection = query external system (Datasphere, S/4HANA, BW) at runtime.
  • Planning: Planning model with dimensions (e.g. account, cost center, time, version). Data entry; allocation and distribution; write-back to model or to source (e.g. S/4HANA).
  • Predictive: Smart insights (outlier, trend); predictive scenario (forecast); classification. Uses embedded analytics and ML.
  • Digital boardroom: Presentation mode with live data; navigation between pages; used in meetings.

Data plane and control plane

Data plane: SAC holds imported data in models/datasets (when using import). For live connection, data stays in source (Datasphere, S/4HANA, BW); SAC queries on demand. Control plane: SAC tenant (admin): users, roles, connections to source systems; BTP entitlements for SAC. See Module 1.

Deployment and integration

Deployment: SaaS only. Integration: S/4HANA (OData, BW connector, or via Datasphere); BW/4HANA; Datasphere (recommended—business layer); IBP; file upload and third-party. SAC is a consumer of data; it does not replace ERP—it visualizes and plans on top of it.

Example: Dashboard from S/4HANA and Datasphere

Finance wants a revenue and cost dashboard in SAC.

  1. Connection (SAC): Admin creates connection to Datasphere (or directly to S/4HANA). In Datasphere, a view already exists: “Revenue and cost by company code and month” (built from S/4HANA tables). SAC uses live connection to this view.
  2. Story (SAC): Author creates story; adds data from connection (Datasphere view). Adds chart: revenue by month (bar chart); table: revenue and cost by company code; filter: fiscal year. Saves and shares with finance team.
  3. Consumption: Users open the story; data is queried live from Datasphere (and thus from S/4HANA). No copy in SAC for live connection. For planning: separate planning model with write-back if needed.

Result: One dashboard; single source of truth (S/4HANA via Datasphere).

Key concepts

Story: Main artifact—pages with widgets (chart, table, etc.) and data binding. Model vs dataset: Model = multidimensional (dimensions, measures); dataset = flat table for simpler stories. Live vs import: Live = real-time from source; import = snapshot in SAC. Datasphere: SAP recommends Datasphere as the semantic layer; SAC connects to Datasphere for S/4HANA and other sources (Module 21).
